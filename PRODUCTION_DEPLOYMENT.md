# 🚀 Production Deployment Guide\n\n## Prerequisites\n\n- Ubuntu 20.04 LTS or later\n- Python 3.11+\n- Docker & Docker Compose\n- Nginx (reverse proxy)\n- Let's Encrypt (SSL certificates)\n- 2GB RAM minimum\n\n---\n\n## Option 1: Standalone Deployment (Gunicorn + Nginx)\n\n### Step 1: System Setup\n\n```bash\n# Update system\nsudo apt-get update && sudo apt-get upgrade -y\n\n# Install dependencies\nsudo apt-get install -y python3.11 python3-pip nginx git certbot python3-certbot-nginx\n\n# Create app user\nsudo useradd -m -s /bin/bash atsapp\n\n# Clone repository\ncd /opt\nsudo git clone https://github.com/sairamkarpurapu2803/Ats_resume.git\ncd Ats_resume\nsudo git checkout fastapi-migration\nsudo chown -R atsapp:atsapp /opt/Ats_resume\n```\n\n### Step 2: Python Environment\n\n```bash\ncd /opt/Ats_resume\n\n# Create virtual environment\nsudo -u atsapp python3.11 -m venv venv\nsudo -u atsapp venv/bin/pip install --upgrade pip\nsudo -u atsapp venv/bin/pip install -r requirements.txt\nsudo -u atsapp venv/bin/pip install gunicorn\n```\n\n### Step 3: Environment Configuration\n\n```bash\n# Copy environment template\nsudo -u atsapp cp .env.example /opt/Ats_resume/.env\n\n# Edit with your settings\nsudo -u atsapp nano /opt/Ats_resume/.env\n\n# Set these values:\n# ENV=production\n# GEMINI_API_KEY=your_actual_key_here\n# DEBUG=False\n```\n\n### Step 4: Systemd Service\n\n```bash\n# Create systemd service file\nsudo tee /etc/systemd/system/ats-resume.service > /dev/null <<'EOF'\n[Unit]\nDescription=ATS Resume Optimizer API\nAfter=network.target\n\n[Service]\nType=notify\nUser=atsapp\nWorkingDirectory=/opt/Ats_resume\nEnvironment=\"PATH=/opt/Ats_resume/venv/bin\"\nEnvironmentFile=/opt/Ats_resume/.env\nExecStart=/opt/Ats_resume/venv/bin/gunicorn \\\n  --config gunicorn_config.py \\\n  --env PYTHONUNBUFFERED=1 \\\n  main:app\nExecReload=/bin/kill -s HUP $MAINPID\nRestart=always\nRestartSec=10\nStandardOutput=journal\nStandardError=journal\n\n[Install]\nWantedBy=multi-user.target\nEOF\n\n# Enable and start service\nsudo systemctl daemon-reload\nsudo systemctl enable ats-resume\nsudo systemctl start ats-resume\n\n# Check status\nsudo systemctl status ats-resume\n```\n\n### Step 5: Nginx Configuration\n\n```bash\n# Copy nginx config\nsudo cp /opt/Ats_resume/nginx.conf /etc/nginx/sites-available/ats-resume\n\n# Create symlink\nsudo ln -s /etc/nginx/sites-available/ats-resume /etc/nginx/sites-enabled/\n\n# Edit domain name\nsudo nano /etc/nginx/sites-available/ats-resume\n# Replace: ats-resume-api.example.com with your actual domain\n\n# Test nginx config\nsudo nginx -t\n\n# Reload nginx\nsudo systemctl reload nginx\n```\n\n### Step 6: SSL Certificate Setup\n\n```bash\n# Install Let's Encrypt certificate\nsudo certbot certonly --nginx -d your-domain.com -d www.your-domain.com\n\n# Auto-renewal setup\nsudo systemctl enable certbot.timer\nsudo systemctl start certbot.timer\n\n# Verify renewal\nsudo certbot renew --dry-run\n```\n\n### Step 7: Monitoring\n\n```bash\n# View service status\nsudo systemctl status ats-resume\n\n# View logs (real-time)\nsudo journalctl -u ats-resume -f\n\n# View access logs\nsudo tail -f /opt/Ats_resume/logs/access.log\n\n# View error logs\nsudo tail -f /opt/Ats_resume/logs/error.log\n```\n\n---\n\n## Option 2: Docker Compose Deployment\n\n### Step 1: Install Docker\n\n```bash\n# Install Docker\ncurl -fsSL https://get.docker.com -o get-docker.sh\nsudo sh get-docker.sh\n\n# Install Docker Compose\nsudo curl -L \"https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)\" -o /usr/local/bin/docker-compose\nsudo chmod +x /usr/local/bin/docker-compose\n```\n\n### Step 2: Clone Repository\n\n```bash\ncd /opt\nsudo git clone https://github.com/sairamkarpurapu2803/Ats_resume.git\ncd Ats_resume\nsudo git checkout fastapi-migration\nsudo chown -R $USER:$USER /opt/Ats_resume\n```\n\n### Step 3: Configure Environment\n\n```bash\ncd /opt/Ats_resume\ncp .env.example .env\nnano .env\n\n# Set:\n# ENV=production\n# GEMINI_API_KEY=your_actual_key_here\n```\n\n### Step 4: Deploy with Docker Compose\n\n```bash\n# Build and start services\ndocker-compose up -d\n\n# Verify services running\ndocker-compose ps\n\n# View logs\ndocker-compose logs -f ats-resume-api\n\n# Stop services\ndocker-compose down\n```\n\n### Step 5: SSL with Nginx Reverse Proxy\n\n```bash\n# Create nginx docker-compose override\nsudo tee docker-compose.prod.yml > /dev/null <<'EOF'\nversion: '3.8'\n\nservices:\n  nginx:\n    image: nginx:latest\n    container_name: ats-resume-nginx\n    ports:\n      - \"80:80\"\n      - \"443:443\"\n    volumes:\n      - ./nginx.conf:/etc/nginx/nginx.conf:ro\n      - /etc/letsencrypt:/etc/letsencrypt:ro\n    depends_on:\n      - ats-resume-api\n    restart: unless-stopped\nEOF\n\n# Deploy with override\ndocker-compose -f docker-compose.yml -f docker-compose.prod.yml up -d\n```\n\n---\n\n## Option 3: Kubernetes Deployment\n\n### Step 1: Create Deployment YAML\n\n```bash\ncat > k8s-deployment.yaml <<'EOF'\napiVersion: apps/v1\nkind: Deployment\nmetadata:\n  name: ats-resume-api\nspec:\n  replicas: 3\n  selector:\n    matchLabels:\n      app: ats-resume-api\n  template:\n    metadata:\n      labels:\n        app: ats-resume-api\n    spec:\n      containers:\n      - name: api\n        image: your-registry/ats-resume:latest\n        ports:\n        - containerPort: 8000\n        env:\n        - name: ENV\n          value: \"production\"\n        - name: GEMINI_API_KEY\n          valueFrom:\n            secretKeyRef:\n              name: ats-resume-secret\n              key: gemini-api-key\n        resources:\n          requests:\n            memory: \"512Mi\"\n            cpu: \"250m\"\n          limits:\n            memory: \"1Gi\"\n            cpu: \"500m\"\n        livenessProbe:\n          httpGet:\n            path: /api/v1/health\n            port: 8000\n          initialDelaySeconds: 30\n          periodSeconds: 10\n        readinessProbe:\n          httpGet:\n            path: /api/v1/ready\n            port: 8000\n          initialDelaySeconds: 10\n          periodSeconds: 5\n---\napiVersion: v1\nkind: Service\nmetadata:\n  name: ats-resume-api\nspec:\n  selector:\n    app: ats-resume-api\n  ports:\n  - protocol: TCP\n    port: 80\n    targetPort: 8000\n  type: LoadBalancer\nEOF\n```\n\n### Step 2: Deploy to Kubernetes\n\n```bash\n# Create namespace\nkubectl create namespace ats-resume\n\n# Create secret\nkubectl create secret generic ats-resume-secret \\\n  --from-literal=gemini-api-key=your_key_here \\\n  -n ats-resume\n\n# Deploy\nkubectl apply -f k8s-deployment.yaml -n ats-resume\n\n# Check status\nkubectl get pods -n ats-resume\nkubectl get svc -n ats-resume\n\n# View logs\nkubectl logs -f deployment/ats-resume-api -n ats-resume\n```\n\n---\n\n## Performance Tuning\n\n### Gunicorn Workers\n\n```python\n# Edit gunicorn_config.py\n# Formula: (2 × CPU cores) + 1\n# For 4-core: workers = 9\n# For 8-core: workers = 17\n\nworkers = 9\nworker_class = \"uvicorn.workers.UvicornWorker\"\nmax_requests = 1000\nmax_requests_jitter = 100\n```\n\n### Nginx Caching\n\n```nginx\n# Add to nginx.conf\nproxy_cache_path /var/cache/nginx levels=1:2 keys_zone=api_cache:10m max_size=1g inactive=60m;\n\nlocation /api/v1/health {\n    proxy_cache api_cache;\n    proxy_cache_valid 200 10s;\n}\n```\n\n### Database Connection Pooling\n\n```bash\n# If using database in future, set in .env\nDB_POOL_SIZE=20\nDB_MAX_OVERFLOW=10\nDB_POOL_TIMEOUT=30\n```\n\n---\n\n## Monitoring & Logging\n\n### View Service Status\n\n```bash\n# Systemd\nsudo systemctl status ats-resume\nsudo journalctl -u ats-resume -f -n 100\n\n# Docker\ndocker-compose logs -f --tail=100\n\n# Kubernetes\nkubectl logs -f deployment/ats-resume-api -n ats-resume\n```\n\n### Health Checks\n\n```bash\n# Check API health\ncurl https://your-domain.com/api/v1/health\n\n# Check readiness\ncurl 22/tcp\nsudo ufw allow 80/tcp\nsudo ufw allow 443/tcp\nsudo ufw default deny incoming\nsudo ufw default allow outgoing\n```\n\n### SSH Security\n\n```bash\n# Edit SSH config\nsudo nano /etc/ssh/sshd_config\n\n# Set:\n# PasswordAuthentication no\n# PermitRootLogin no\n# Port 2222 (optional, non-standard port)\n\nsudo systemctl restart sshd\n```\n\n### Fail2Ban Protection\n\n```bash\n# Install\nsudo apt-get install -y fail2ban\n\n# Create config\nsudo tee /etc/fail2ban/jail.local > /dev/null <<'EOF'\n[DEFAULT]\nbantime = 3600\nfindtime = 600\nmaxretry = 5\n\n[sshd]\nenabled = true\n\n[nginx-http-auth]\nenabled = true\n\n[nginx-noscript]\nenabled = true\nEOF\n\nsudo systemctl enable fail2ban\nsudo systemctl start fail2ban\n```\n\n---\n\n## Backup & Recovery\n\n### Create Backup Script\n\n```bash\n#!/bin/bash\n# backup-ats-resume.sh\n\nDATE=$(date +%Y%m%d_%H%M%S)\nBACKUP_DIR=\"/backups\"\n\nmkdir -p $BACKUP_DIR\n\n# Backup application\ntar -czf $BACKUP_DIR/ats-resume-$DATE.tar.gz \\\n  /opt/Ats_resume/logs \\\n  /opt/Ats_resume/exports \\\n  /opt/Ats_resume/.env\n\n# Keep only last 7 days\nfind $BACKUP_DIR -name \"ats-resume-*.tar.gz\" -mtime +7 -delete\n\necho \"Backup completed: $BACKUP_DIR/ats-resume-$DATE.tar.gz\"\n```\n\n### Schedule with Cron\n\n```bash\n# Make script executable\nsudo chmod +x /usr/local/bin/backup-ats-resume.sh\n\n# Add to crontab (2 AM daily)\nsudo sh -c 'echo \"0 2 * * * /usr/local/bin/backup-ats-resume.sh\" | crontab'\n```\n\n---\n\n## Troubleshooting\n\n### Service Won't Start\n\n```bash\n# Check detailed error\nsudo systemctl status ats-resume -l\nsudo journalctl -u ats-resume -n 50\n\n# Check syntax\nsudo -u atsapp /opt/Ats_resume/venv/bin/python -m py_compile main.py\n```\n\n### High Memory Usage\n\n```bash\n# Check processes\nps aux | grep gunicorn\n\n# Reduce worker count in gunicorn_config.py\nworkers = 4  # Reduce from 9\n\n# Restart service\nsudo systemctl restart ats-resume\n```\n\n### SSL Certificate Issues\n\n```bash\n# Check expiry\nsudo certbot certificates\n\n# Renew manually\nsudo certbot renew\n\n# Force renewal\nsudo certbot renew --force-renewal\n```\n\n### Nginx Connection Refused\n\n```bash\n# Check if upstream is running\nsudo systemctl status ats-resume\n\n# Test nginx config\nsudo nginx -t\n\n# Reload nginx\nsudo systemctl reload nginx\n```\n\n---\n\n## Cleanup & Uninstall\n\n```bash\n# Stop service\nsudo systemctl stop ats-resume\nsudo systemctl disable ats-resume\n\n# Remove systemd service\nsudo rm /etc/systemd/system/ats-resume.service\nsudo systemctl daemon-reload\n\n# Remove application\nsudo rm -rf /opt/Ats_resume\n\n# Remove nginx config\nsudo rm /etc/nginx/sites-available/ats-resume\nsudo rm /etc/nginx/sites-enabled/ats-resume\nsudo systemctl reload nginx\n\n# Remove user\nsudo userdel atsapp\n```\n\n---\n\n## Support\n\nFor issues:\n1.
